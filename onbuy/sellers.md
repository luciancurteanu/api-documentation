# Sellers

## Sellers: View

**Method:** `GET`

**URL:** `{{host}}/sellers/{{seller_id}}`

**Authentication:** Required

**Example Response:**
```json
{
    "data": {
        "seller_id": "001",
        "site_id": "2000",
        "seller_name": "Example Seller Name",
        "company_name": "Example Company Name"
    }
}
```
